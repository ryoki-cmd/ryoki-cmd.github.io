プライバシーポリシー / Privacy Policy

最終更新日：2026年9月28日

「くらし整えメモ 投稿ツール（Kurashi Seiri Memo posting tool）」（以下「本アプリ」）は、運営者が自分自身の SNS アカウント（Pinterest・Instagram・Threads・X・YouTube）に投稿するためだけに使う個人用ツールです。

1. 取得する情報

本アプリは、各 SNS の API を通じて、運営者本人のアカウントの情報と、本アプリが作成した投稿の情報（反応の数、投稿についた公開コメント）を扱います。コメントは返信のためにのみ使い、それ以外の第三者の個人情報は取得しません。

2. 利用目的

取得した情報は、運営者本人のアカウントへの投稿の作成・管理と、投稿の成績の確認にのみ使用します。

3. 保存と第三者提供

アクセストークンは運営者のパソコン内にのみ保存し、第三者に提供・販売することはありません。

4. アフィリエイトについて

本サイトおよび SNS の投稿には、アフィリエイトのリンクが含まれることがあります。広告であることを表示しています。

5. アクセス解析

本サイトは、ページの表示回数を知るために Cloudflare Web Analytics を使用しています。Cookie を使わず、個人を特定する情報は収集しません。また、Google 検索での表示状況を Google Search Console で確認しています。

6. YouTube API サービスの利用について

本アプリは YouTube API サービスを利用して、運営者本人の YouTube チャンネルに動画をアップロードします。本アプリを利用することで、YouTube 利用規約に同意したことになります。YouTube API サービスで扱う情報については、Google プライバシー ポリシーもご確認ください。

本アプリが YouTube API サービスを通じて扱うのは、運営者本人のチャンネル情報（チャンネル名）と、本アプリがアップロードした動画の情報のみです。他のユーザーの情報は取得・保存・共有しません。

7. データの保存期間と削除

アクセストークンなどの認証情報は運営者のパソコン内にのみ保存し、不要になった時点で削除します。YouTube のデータへのアクセス許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。取り消した場合、本アプリが保存している認証情報は7日以内に削除します。

8. お問い合わせ

本ポリシーに関するお問い合わせは、お問い合わせのページからご連絡ください。
