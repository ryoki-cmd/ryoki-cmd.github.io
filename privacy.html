プライバシーポリシー / Privacy Policy

最終更新日：2026年9月27日

「Pin Helper」（以下「本アプリ」）は、運営者が自分自身の SNS アカウント（Pinterest・Instagram）に投稿するためだけに使う個人用ツールです。

1. 取得する情報

本アプリは、各 SNS の API を通じて、運営者本人のアカウントの情報と、本アプリが作成した投稿の情報のみを扱います。運営者以外の第三者の個人情報は取得しません。

2. 利用目的

取得した情報は、運営者本人のアカウントへの投稿の作成・管理と、投稿の成績の確認にのみ使用します。

3. 保存と第三者提供

アクセストークンは運営者のパソコン内にのみ保存し、第三者に提供・販売することはありません。

4. アフィリエイトについて

本サイトおよび SNS の投稿には、アフィリエイトのリンクが含まれることがあります。広告であることを表示しています。

5. アクセス解析

本サイトはアクセス解析ツールを使用していません。

6. お問い合わせ

本ポリシーに関するお問い合わせは、Instagram のプロフィールからご連絡ください。

English summary: Pin Helper is a personal tool used only by its owner to publish to the owner's own Pinterest and Instagram accounts. It accesses only the owner's own account data via official APIs, stores access tokens only on the owner's computer, and never shares or sells any data. Some posts and pages contain affiliate links and are labeled as ads.
