プライバシーポリシー / Privacy Policy

最終更新日：2026年9月23日

「Pin Helper」（以下「本アプリ」）は、運営者が自分自身の Pinterest アカウントにピンを作成するためだけに使う個人用ツールです。

1. 取得する情報

本アプリは、Pinterest API を通じて、運営者本人のアカウントのボード情報と、本アプリが作成したピンの情報のみを扱います。運営者以外の第三者の個人情報は取得しません。

2. 利用目的

取得した情報は、運営者本人のアカウントへのピンの作成・管理にのみ使用します。

3. 保存と第三者提供

アクセストークンは運営者のパソコン内にのみ保存し、第三者に提供・販売することはありません。

4. アフィリエイトについて

本アプリで作成するピンには、楽天アフィリエイトのリンクが含まれます。ピンには広告であることを表示します。

5. お問い合わせ

本ポリシーに関するお問い合わせは、Pinterest のプロフィールからご連絡ください。

English summary: Pin Helper is a personal tool used only by its owner to create pins on the owner's own Pinterest account. It accesses only the owner's boards and pins via the Pinterest API, stores access tokens only on the owner's computer, and never shares or sells any data. Pins may contain Rakuten affiliate links and are labeled as ads.
